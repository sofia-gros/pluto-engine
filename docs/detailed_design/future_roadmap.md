# PlutoEngine 将来の開発ロードマップ (Future Roadmap)

このドキュメントは、PlutoEngine が既存の汎用エンジン（Phaser, PixiJS 等）と肩を並べ、かつ独自のパフォーマンス優位性（ゼロアロケーション・SoA・インスタンシング）を維持しながら進化するための実装計画です。

## 1. 階層構造（Scene Graph）の SoA 実装
**概要:** 親コンテナの移動や回転に子要素が追従する仕組み。
**設計:** 
- オブジェクトの入れ子（Tree構造）を作らず、`arena.parentId` という配列を保持する。
- 描画前のコンピュートパスで、ローカル行列からワールド行列への変換を一括計算する。これにより DOD (Data-Oriented Design) のまま階層構造を表現。

## 2. オーディオシステム (SoundManager)
**概要:** Web Audio API を用いた柔軟な音声再生システム。
**設計:**
- 空間オーディオやBGMループ再生、デコードキャッシュの管理。
- 大量の敵が同時に爆発した際などに音が割れないよう、多重再生時のミキシング・リミッター機能を実装。

## 3. タイルマップ (Tilemap) のインスタンシング描画
**概要:** Tiled Editor 形式等のマップデータを高速描画。
**設計:**
- 背景を1枚のテクスチャにするのではなく、マップチップのインデックスをバッファに流し込み、インスタンシングで一括描画。何万タイルあっても 1 Draw Call で処理する。

## 4. 高度なカメラシステム (CameraManager)
**概要:** プレイヤー追従、画面揺らし等の演出。
**設計:**
- Scene ごとに Camera オブジェクト（Projection / View 行列の管理）を持たせ、ズームや回転、ワールド境界（World Bounds）の制限、マルチカメラ分割画面に対応する。

## 5. 入力の拡充 (Touch / Gamepad)
**概要:** スマホおよびコンシューマーライクな操作のサポート。
**設計:**
- マルチタッチのハンドリング、バーチャルジョイスティックUIの組み込み。
- Gamepad API の統合。
