# Variable: DEFAULT\_FRAME\_SIZE

> `const` **DEFAULT\_FRAME\_SIZE**: `32` = `32`

Defined in: [renderer/src/InstanceLayout.ts:62](https://github.com/sofia-gros/pluto-engine/blob/d3e5151654e0015799b06bdbbf560a8da4522843/packages/renderer/src/InstanceLayout.ts#L62)

テクスチャ未設定のスプライトに与えるフレーム寸法 (px)。

Phaser は `__DEFAULT` テクスチャ (32x32) をスプライトの既定として使います。
実際は透明なので見えないですが、サイズと当たり判定は 32px として成立します。
