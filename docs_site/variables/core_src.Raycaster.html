    • intersectLine: function
      • intersectLine(
            line: RayLine,
            shapes: ArrayLike<number>,
            stride: number,
            out: Float32Array,
            tolerance?: number,
        ): number

        指定 stride の SoA 図形群を線分と交差判定します。

        stride が 3 なら円、6 なら三角形、4 なら矩形として扱います。 線分群との交差には Raycaster.intersectLineSegments を使ってください。

        Parameters

        • line: RayLine

          線分 [x1, y1, x2, y2]

        • shapes: ArrayLike<number>

          図形群の SoA バッファ

        • stride: number

          1 図形あたりの要素数

        • out: Float32Array

          交差結果を詰めるバッファ（RAY_HIT_STRIDE 個ずつ）

        • tolerance: number = 1e-6

          境界の判定に使う許容誤差

        Returns number

        out に詰めた交差結果の数

      • intersectLineSegments(
            line: RayLine,
            segments: ArrayLike<number>,
            out: Float32Array,

        ): number

        線分群（stride 4 の [x1, y1, x2, y2]）と線分の交差を走査します。

        線どうしの交差なので法線は求めません（NormalX / NormalY は 0）。 平行（または同一線）な場合は交差として扱いません。

        Parameters
