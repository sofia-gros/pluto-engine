# パフォーマンス & ベンチマーク (Performance & Benchmarks)

PlutoEngine は、**ゼロアロケーション (Zero-Allocation)**、**Structure of Arrays (SoA)**、そして **WebGL2 のハードウェアインスタンシング** を活用し、ブラウザ上で数十万体規模のエンティティを高速・安定して動かすために設計された 2D ゲームエンジンです。

## 🚀 v1.0.7 から v1.0.9 での進化とアーキテクチャ改善

v1.0.9 では、大規模エンティティシミュレーション時のボトルネックとなっていたメモリ操作と GPU 転送オーバーヘッドを根本から見直し、大幅なフレームレート向上と安定性を実現しました。

### 1. Data Packing の完全消滅 (6.3ms ➔ 0.0ms)
- **旧 (v1.0.7)**: エンティティ削除時に配列の穴埋め走査（データパッキング）が発生し、30万体シミュレーション時に毎フレーム約 **6.3ms** のオーバーヘッドとなっていました。
- **新 (v1.0.9)**: **Swap-Remove 式 Sparse Set** を導入したことで、配列が常に密（Dense）に維持され、パッキング処理が **完全消滅 (0.0ms)** しました。

### 2. CPU ➔ GPU 転送時間の 84% 削減 (Dirty Flags)
- **旧 (v1.0.7)**: 毎フレーム全エンティティの全属性バッファを GPU に転送（約 2.0ms）。
- **新 (v1.0.9)**: **Dirty Flags** 機構により、値に変更があった属性のみを選択的に転送。GPU Upload 時間を **0.32 ms (-84% 削減)** に圧縮しました。

### 3. Continuum Crowds / 流体解法の最適化
- 128x128 圧力場ガウス・ザイデル緩和のメモリアクセス局所化とキャッシュヒット率向上により、流体圧力解法を **0.9ms ➔ 0.19ms (4.7倍 高速化)** しました。

### 4. Flow Field ステアリングの高速化 & 双線形補間 (Bilinear Interpolation)
- **事前計算速度場**: 128x128（16,384セル）の速度場を一括計算し、エンティティごとの冗長な勾配計算と `Math.hypot` のオーバーヘッドを排除。
- **双線形補間**: 4近傍の速度ベクトルをサブピクセル補間することで、セル境界でのカクつきのない滑らかな群集流体移動を実現しています。
