# アーキテクチャ

PlutoEngineは、従来のオブジェクト指向設計（OOD）で発生するパフォーマンス上の問題に対処するため、**データ指向設計（Data-Oriented Design）**を採用しています。

## Structure of Arrays (SoA)

エンティティのデータ（位置、速度、カラーなど）は、個々のオブジェクトとしてではなく、連続した `Float32Array` や `Uint32Array` などの **TypedArray** に格納されます。

## ゼロアロケーションの原則

メインループ（`update` や `render`）内では、`new` やオブジェクトリテラル `{}`、配列の `.push()` を含むすべての動的メモリ割り当てを禁止しています。これにより、GCの介入を防ぎ、フレームレートのドロップを完全に排除します。
