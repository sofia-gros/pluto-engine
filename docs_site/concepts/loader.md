# アセットローダー (Asset Loader)

PlutoEngineのアセットローダーは、ゲーム起動時の事前ロードと、実行時のゼロアロケーションを両立するように設計されています。

## 非同期ストリーミングとアリーナ展開

テクスチャ、音声、JSONデータなどのリソースは、初期化フェーズで一括ダウンロード（またはストリーミング）されます。
重要なのは、ロードされたデータ（特に画像）がどのようにメモリに配置されるかです。

### テクスチャアトラスとWebGPU

複数の小さなスプライトは、自動的に一枚の巨大なテクスチャアトラスにパッキングされます。
これにより、レンダリング中のテクスチャバインドの切り替え（コンテキストスイッチ）を極限まで減らします。

- 実行時は、SoAアリーナの中に「UV座標のオフセット」と「テクスチャID」の整数のみが保存されます。
- 文字列によるアセットの検索（例: `getSprite("player")`）は初期化時のみ許可され、実行時は高速な数値IDアクセスのみが行われます。

## チャンクベースの動的ロード

大規模なシーンでは、空間分割（モートン順序など）に基づき、必要なチャンクのアセットだけをバックグラウンドのWeb Workerで非同期にロードし、メインスレッドのガベージコレクションを回避しつつGPUに転送します。
