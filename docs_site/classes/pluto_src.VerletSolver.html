    Class VerletSolver

    File

    VerletSolver.ts

    Description

    マントや触手の演出に特化したゼロアロケーションの Verlet 積分ソルバー。

    設計方針:

    • 状態はすべて SoA の TypedArray に置き、毎フレームの new を排除します。
    • 固定点を明示的に持つため、ロープの根元を物体の座標へそのまま追従できます。
    • 拘束の反復回数を増やせば剛性が高まり、減らせば柔らかく動きます。
