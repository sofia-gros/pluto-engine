    addAtlas

    • addAtlas(
          key: string,
          source: HTMLCanvasElement | HTMLImageElement | ImageBitmap | ImageData,
          frames: { h: number; w: number; x: number; y: number }[],
      ): TextureAsset

      アトラス (TexturePacker 形式) を登録・GPU転送します。

      均一グリッドではないため、フレーム UV は呼び出し側が矩形一覧で渡します。 配列順がそのままフレーム番号になるため、 描画時は setFrame(番号) で指定します。

      Parameters

      • key: string

        テクスチャキー

      • source: HTMLCanvasElement | HTMLImageElement | ImageBitmap | ImageData

        画像

      • frames: { h: number; w: number; x: number; y: number }[]

        フレーム矩形 (ピクセル)。配列順 = フレーム番号

      Returns TextureAsset

      • Defined in core/src/loader/TextureManager.ts:168

    • addSpritesheet(
          key: string,
          source: HTMLCanvasElement | HTMLImageElement | ImageBitmap | ImageData,

      スプライトシートからテクスチャを登録・GPU転送します。

      options.frames に明示矩形があればそれを使い、 無ければ frameWidth / frameHeight から均一グリッドを計算します。
