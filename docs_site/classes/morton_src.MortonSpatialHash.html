    • build(): void

      追加済みのエンティティを Morton コード順に Radix Sort します。 32 bit コードを 8 bit ずつ 4 パスで安定的に並べます。 計算量は O(4n) で、桶の全走査は一切行いません。

    query

    • query(x: number, y: number, radius: number, outArray: Uint32Array): number

      指定位置の近傍セル内のエンティティ ID を outArray へ書き込み、件数を返します。 厳密な距離判定 (ブロードフェーズ) は呼び出し側の責務です。 半径が 1 セル以内なら二分探索 1 回で済み、セル走査は起こりません。

      Parameters

      • x: number
      • y: number
      • radius: number
      • outArray: Uint32Array

        呼び出し側が確保した書き込み先。実行中は new しません
