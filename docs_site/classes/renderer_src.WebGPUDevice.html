    setupInstancedAttributes

    • setupInstancedAttributes(
          buffers: Record<string, BufferInfo>,
          activeCount?: number,
          baseInstance?: number,
      ): void

      インスタンス用バッファのバインド内容を記録します。

      pack は行いません。 転送元は InstanceBufferArena の write-through ミラーで、すでに vec4 単位にまとまっています。 そのためこのメソッドは O(1) の記録のみで済みます。

      baseInstance は可視区間の先頭インスタンス番号です。 実際の setVertexBuffer は drawInstanced の中で行います （WebGL2 の VAO と同じ「カメラ単位の属性設定」に合わせます）。

      Parameters

      • buffers: Record<string, BufferInfo>
      • OptionalactiveCount: number
      • baseInstance: number = 0

      Returns void

      Implementation of GraphicsDevice.setupInstancedAttributes

      • Defined in renderer/src/WebGPUDevice.ts:837

    updateBuffer

    • updateBuffer(
          bufferInfo: BufferInfo,
          data:
              | Float32Array<ArrayBufferLike>
              | Uint32Array<ArrayBufferLike>
              | Uint8Array<ArrayBufferLike>,
          srcOffset?: number,
          length?: number,

      packed ミラー配列を GPU へ転送します。

      WebGL2 と同じく subarray を new せず、範囲を直接指定します。
