    Class Group

    File

    Group.ts

    Description

    Phaser 4 互換のグループ。

    設計上の判断 (IMPACT_SCOPE 3.2 の判定 D): Group は SoA 化しません。可変長の子リストは SoA の得意分野ではなく、 使い回し Array で実装し、Pluto のアリーナは汚しません (Group は「CPU 管理のビュー」として arena と並行して持ちます)。

    所属数组は呼び出し側が渡す out を使い回すのが前提です。 毎フレーム getChildren() を呼ぶと new が発生するため、 ホットパスでは forEachInto() を使ってください。
