    add

    • add(config: TweenConfig): Tween

      Phaser 互換の this.tweens.add({ targets, ... }) を受け付けます。

      既存の SoA をそのまま使い、1 プロパティにつき 1 スロットを確保します。 props に 2 つ指定すれば 2 スロットが確保され、常に同じ速度で同期します。

      Parameters

      • config: TweenConfig

      Returns Tween

      Tween ハンドル。killTweensOfGroup(handle.id) にも使えます

    • getGroupProgress(groupId: number): number

      グループの進捗率 (0〜1) を返します。
