    Class PoissonSolver

    単側非圧縮性制約（UIC: Unilateral Incompressibility Constraint）に基づくグリッドポアソンソルバー。 群集流体シミュレーション（Continuum Crowds）や流体シミュレーションで活用される。 ゼロアロケーション原則に従い、SoA (Float32Array) によるヤコビ反復解法を実装。
