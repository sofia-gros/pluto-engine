    Staticstep

    • step(p: XPBDParticles, dt: number, options?: XPBDSolverOptions): void

      1 ステップを解きます。

      処理の流れ:

      1. 位置を速度で積分する
      2. サブステップごとに 1 反復ずつ接触拘束を解く
      3. 速度を新しい位置から再計算する
      4. 摩擦と反発を適用する

      Parameters

      • p: XPBDParticles
      • dt: number
      • options: XPBDSolverOptions = {}

      Returns void
